mero_terminal is a Linux terminal environment repo centered on portable dotfiles and an idempotent install.sh. It manages bash, tmux, Neovim, Yazi, Starship, and related CLI tooling for Debian/Ubuntu and Arch. The repository root contains the dotfiles and installer. A new isolated side project lives under gh-home/, implemented as a Python package with its own pyproject.toml, launcher script, provider adapter layer, and terminal renderer for a profile-centric Git hosting dashboard.
