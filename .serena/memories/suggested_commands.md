Repo commands: `bash install.sh` to install or relink the environment, `bash -n install.sh` to syntax-check installer changes, `git status --short` for local changes. gh-home commands: `gh-home/bin/gh-home` to run the dashboard, `gh-home/bin/gh-home --no-color` for plain output, `python3 -m py_compile gh-home/src/gh_home/*.py gh-home/src/gh_home/adapters/*.py` for syntax checks. Runtime prerequisite: `gh auth login -h github.com` for live GitHub data.
