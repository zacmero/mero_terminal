# Ponytail Help

## Levels
- **Lite** (`/ponytail lite`): Build what is asked, name lazier alternative in one line.
- **Full** (`/ponytail`): Ladder enforced: YAGNI → stdlib → native → one-line → minimum. Default.
- **Ultra** (`/ponytail ultra`): Deletion before addition. Challenges requirements.

## Skills
- `/ponytail`: Lazy senior dev mode.
- `/ponytail-review`: Over-engineering review.
- `/ponytail-audit`: Whole-repo bloat audit.
- `/ponytail-debt`: Harvest `ponytail:` shortcut comments into a tracked ledger.
- `/ponytail-gain`: Measured impact scoreboard.
- `/ponytail-help`: Reference card.

## Deactivate
Say "stop ponytail" or set `"ponytail": { "enabled": false }` in `config.json`.
